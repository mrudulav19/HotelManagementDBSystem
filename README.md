# 🏨 Hotel Booking System — SQL Server

A relational database project built using **Microsoft SQL Server** to manage customers, rooms, room types, bookings, and payments.

The project was created to strengthen practical SQL skills, particularly **JOINs, aggregate functions, date functions, filtering, GROUP BY, and HAVING**.

---

## 📌 Project Overview

The Hotel Booking System stores and analyzes hotel booking information through a relational database.

The database manages:

- Customer information
- Room and room type details
- Hotel bookings
- Payment records
- Booking and revenue analysis

The project focuses primarily on **SQL querying and database design** rather than application development.
